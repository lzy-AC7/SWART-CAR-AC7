# 卡尔曼滤波 - 快速调整指南

## ⚙️ 参数位置

在 **user/inc/common.h** 中找到这三行：

```c
#define KALMAN_Q_VELOCITY       0.01f   // 过程噪声方差
#define KALMAN_R_VELOCITY       10.0f   // 测量噪声方差  
#define KALMAN_P_VELOCITY       1.0f    // 初始估计误差
```

## 🎯 快速调参方案

### A. 默认方案（推荐 ⭐）
```c
#define KALMAN_Q_VELOCITY       0.01f
#define KALMAN_R_VELOCITY       10.0f
#define KALMAN_P_VELOCITY       1.0f
```
**特点**：平衡快速反应和位置精度

---

### B. 精度优先（位置保证 ✓）
```c
#define KALMAN_Q_VELOCITY       0.005f
#define KALMAN_R_VELOCITY       5.0f
#define KALMAN_P_VELOCITY       1.0f
```
**适用于**：
- ✓ 长距离比赛（>30米）
- ✓ 精确停车
- ✓ 地图匹配
- ✗ 快速动态环境

---

### C. 响应优先（速度快 ↗）
```c
#define KALMAN_Q_VELOCITY       0.05f
#define KALMAN_R_VELOCITY       20.0f
#define KALMAN_P_VELOCITY       1.0f
```
**适用于**：
- ✓ 短距离竞速
- ✓ 躲障快速反应
- ✓ 快速加减速
- ✗ 长距离累积误差

---

### D. 聪明混合方案
```c
#define KALMAN_Q_VELOCITY       0.015f  // 稍高于默认
#define KALMAN_R_VELOCITY       8.0f    // 稍低于默认
#define KALMAN_P_VELOCITY       1.5f    // 初始信息更不确定
```
**特点**：自适应能力最强

在 debug.c 中添加以下数据输出来观察效果：

```c
// 观察卡尔曼融合前后的对比
justfloat_add(4, v_x_encoder, v_x_car, v_x_imu, acc_x);
// v_x_encoder: 编码器原始速度
// v_x_car:    卡尔曼融合后速度 ← 最终输出
// v_x_imu:    加速度积分速度
// acc_x:      加速度值
```

### 看图表时的判断：

**v_x_car 应该是什么样？**
```
理想情况：v_x_car ≈ (v_x_encoder 的平滑版本) + (快速响应)
        = 既跟踪编码器的长期趋势
        + 快速响应加速度的短期波动
```

**信号应该看起来**：
- ✅ 光滑（不抖动）
- ✅ 跟踪编码器但更平滑
- ✅ 对加速度有快速响应
- ❌ 不应该远离编码器值太多
- ❌ 不应该有高频抖动

## 🛠️ 调参流程

### 第1步：基准测试（保持默认参数）
```
测试内容：直线走20米，测位置误差
记录值：x_world 最终值 vs 实际值
(参考：编码器精度 ±2%，目标 <3%)
```

### 第2步：根据表现选择方向
```
情况1：位置误差较大（>3%）  → 用方案B（精度优先）
情况2：反应有延迟感（加速慢）→ 用方案C（响应优先）
情况3：都还不错            → 留在默认或试D
```

### 第3步：微调（±0.005微调）
```c
// 例如，基于方案B想要稍快反应：
#define KALMAN_Q_VELOCITY       0.01f   // ← 从0.005增加
#define KALMAN_R_VELOCITY       8.0f    // 保持较低
```

### 第4步：验证（跑完整测试）
```
✓ 走S弯：观察横向对齐误差
✓ 快加速：观察响应延迟
✓ 长直线：观察累积误差
✓ 停车：观察最后摆动幅度
```

## ⚠️ 常见问题

### Q1: v_x_car 跳变明显
**原因**：R 太大（不信任编码器）
**解决**：降低 R 值，如 10.0 → 8.0 或 5.0

### Q2: 加速反应很慢
**原因**：Q 太小（过度信任编码器）
**解决**：提高 Q 值，如 0.01 → 0.03 或 0.05

### Q3: 位置漂移（长时间走直线偏离）
**原因**：说明加速度计零偏问题，或 Q 太大
**解决**：  
- 先检查加速度计标定是否完成
- 试试降低 Q，如 0.01 → 0.005

### Q4: 停车后位置还在变化
**原因**：这很正常（<1cm/分钟是合理的）
**解决**：如果漂移 >10cm/分钟，检查：
- acc_x/acc_y 标定
- 编码器线数配置是否正确
